# Pokémon AI Agent — AI-Powered Strategy Assistant

The Pokémon AI Agent is a Python-based AI assistant that provides real-time Pokémon strategy insights for both casual and competitive players. Built with LangChain, GPT-4o Mini, Gradio, and MongoDB, the system integrates JSON data from multiple Pokémon generations and formats like Smogon (movesets & strategies).

The system offers two interfaces that share the same core logic. The web interface (`app.py`) uses Gradio to create a chatbot with a Pokémon sprite gallery, processing queries through the agent pipeline and displaying formatted markdown responses with visual sprites. The terminal interface (`main.py`) is a simplified CLI version that uses the same processing logic but without image rendering.

The architecture is built around several key components. Data models (`models.py`) define Pydantic schemas like TeamPokemon, TeamSearchResult, and AllTeamSearchResult that enforce structured, parseable outputs for movesets and teams instead of plain text. Tools (`tools.py`) provide agent-accessible functions including Smogon searches, team searches, DuckDuckGo for general information, and utilities for Pokémon/tier detection and HTML cleaning. The LLM decides when to call these tools through tool-calling. Utilities (`utils.py`) handle data normalization and formatting throughout the system, cleaning inconsistent Pokémon names, normalizing tier formats ("Overused" → "OU"), matching sprites from filenames, and transforming structured outputs into readable markdown. Shared logic (`shared.py`) contains core agent creation, memory management, and response formatting functions used by both interfaces.

When a user submits a query like "Give me a good OU team with Garchomp," the system processes it through several stages. First, `extract_species_tier_gen()` identifies Pokémon names, tier, and generation from the query. The system then classifies the query as team-building, multi-Pokémon comparison, single-Pokémon strategy, or general discussion, selecting the appropriate prompt template from `utils.py`. ConversationBufferMemory maintains chat history for context, automatically clearing when a new Pokémon topic is detected to keep conversations relevant. An AgentExecutor wraps ChatOpenAI with the selected prompt and available tools, allowing the agent to autonomously call functions like `team_search` or `combined_smogon_search` to query Smogon JSON data. The structured results (TeamSearchResult, AllTeamSearchResult) are then formatted into clean markdown with proper spacing and headers. Finally, the formatted response appears in the Gradio chatbot with sprites or as terminal output.

The system features intelligent query classification that automatically detects whether users want teams, strategies, comparisons, or general information. Pydantic models ensure consistent, parseable outputs throughout the pipeline. Multi-generation support works across all Pokémon generations with normalized data handling. The context-aware memory system maintains conversation context while adapting to topic changes, and the web interface displays relevant Pokémon sprites alongside responses for enhanced user experience.
